# `wx_channels_download` 分享链接解析实现调查

查阅日期：2026-09-29。上游 `main` 快照：[`124f044235bc706fe796c043a14ff442a150ae5d`](https://github.com/ltaoo/wx_channels_download/tree/124f044235bc706fe796c043a14ff442a150ae5d)（提交日期 2026-09-15）。以下源码链接固定到该提交；腾讯的两个接口属于上游使用的非公开 Web 接口，行为可能变化。

## 请求链

1. Worker 接受 `POST /api/fetch_video_profile`，JSON 请求体是 `{"url":"<视频号分享链接>"}`。它先执行 API 访问认证，再进入解析处理器。[Worker 路由与认证顺序](https://github.com/ltaoo/wx_channels_download/blob/124f044235bc706fe796c043a14ff442a150ae5d/internal/workers/sph/worker.js#L18-L55)、[处理器](https://github.com/ltaoo/wx_channels_download/blob/124f044235bc706fe796c043a14ff442a150ae5d/internal/workers/sph/worker.js#L403-L439)
2. `parseShareUrl` 使用部署时注入的元宝 Web Cookie，请求 `https://yuanbao.tencent.com/api/weixin/get_parse_result`，提交 `type=video_channel_url`、分享链接和 `scene=1`。响应必须含 `data.wx_export_id`；随后从 `data.playable_url` 的查询参数取 `token`（`generalToken`）和 `eid`（`exportId`）。这是登录态和动态令牌参与的解析，不是从分享链接文本直接推导媒体地址。[元宝请求](https://github.com/ltaoo/wx_channels_download/blob/124f044235bc706fe796c043a14ff442a150ae5d/internal/workers/sph/worker.js#L150-L210)、[参数提取](https://github.com/ltaoo/wx_channels_download/blob/124f044235bc706fe796c043a14ff442a150ae5d/internal/workers/sph/worker.js#L354-L385)
3. `getFeedInfo` 将 `generalToken` 与 `exportId` 送到 `https://channels.weixin.qq.com/finder-preview/api/feed/get_feed_info`，得到包含 `data.feedInfo`、`data.authorInfo` 的 feed 响应。上游查询页面从 `h264VideoInfo.videoUrl`、`h265VideoInfo.videoUrl`、`videoUrl` 依次选媒体地址，也读取 `picInfo` 和封面。[feed 请求](https://github.com/ltaoo/wx_channels_download/blob/124f044235bc706fe796c043a14ff442a150ae5d/internal/workers/sph/worker.js#L212-L350)、[前端字段读取](https://github.com/ltaoo/wx_channels_download/blob/124f044235bc706fe796c043a14ff442a150ae5d/internal/workers/sph/index.html#L468-L490)

## 凭证和错误定位

- Worker 的 `ACCESS_CREDENTIAL` 是**调用 Worker API 的凭证**，支持 `Authorization: Bearer <凭证>`，也支持用户名固定为 `wxchannels` 的 Basic Auth。未提供或不匹配时，API 直接返回 HTTP `401`、`{"error":"unauthorized"}`；未配置该环境变量时返回 `503`。此时尚未请求元宝，不能据此判断元宝 Cookie 或分享链接是否有效。[认证实现](https://github.com/ltaoo/wx_channels_download/blob/124f044235bc706fe796c043a14ff442a150ae5d/internal/workers/sph/worker.js#L72-L143)
- Worker 的 `COOKIE` 是**元宝 Web 登录 Cookie**，仅用于上面第 2 步。元宝 HTTP 失败在 Worker 中成为 `parse share url: parseShareUrl: http <状态码>`；缺少 `wx_export_id` 成为 `parse share url: parseShareUrl: missing wx_export_id`；这些异常由处理器返回 HTTP `500`。因此 Cookie 失效、接口变更或响应不符与 Worker 自身的 `401 unauthorized` 是不同故障。上游文档称 Cookie 有效期约一月，失效需更新；这只是上游的操作说明，不是固定有效期保证。[元宝错误处理](https://github.com/ltaoo/wx_channels_download/blob/124f044235bc706fe796c043a14ff442a150ae5d/internal/workers/sph/worker.js#L187-L209)、[异常包装与 HTTP 返回](https://github.com/ltaoo/wx_channels_download/blob/124f044235bc706fe796c043a14ff442a150ae5d/internal/workers/sph/worker.js#L354-L365)、[Cookie 维护说明](https://github.com/ltaoo/wx_channels_download/blob/124f044235bc706fe796c043a14ff442a150ae5d/docs/cli/deploy.md#L151-L169)
- feed HTTP 失败或响应中的非零 `errCode` 会使 Worker 返回 `500`；`data.errMsg` 表示视频不可播放时，返回 `422`，带 `code=FEED_INFO_UNAVAILABLE` 和 `details`。这可供 Skill 给出不同错误提示。[feed 错误判断](https://github.com/ltaoo/wx_channels_download/blob/124f044235bc706fe796c043a14ff442a150ae5d/internal/workers/sph/worker.js#L243-L350)、[异常响应](https://github.com/ltaoo/wx_channels_download/blob/124f044235bc706fe796c043a14ff442a150ae5d/internal/workers/sph/worker.js#L423-L439)
- 当前源码只对 `/api/` 路径认证，根页面和静态资源可直接打开；[部署文档](https://github.com/ltaoo/wx_channels_download/blob/124f044235bc706fe796c043a14ff442a150ae5d/docs/cli/deploy.md#L171-L196) 却写“页面、静态资源和 API 均需认证”，以源码为准。[源码分支](https://github.com/ltaoo/wx_channels_download/blob/124f044235bc706fe796c043a14ff442a150ae5d/internal/workers/sph/worker.js#L72-L90)

## 本项目现状与已选方案

此前 Skill 的 [`resolve_link.py`](../../plugins/wx-video-account-notes/skills/wx-video-account-notes/runtime/resolve_link.py) 向上游作者的 Worker 发送不带访问凭证的 `POST` 请求，因此得到 `401 unauthorized`。这发生在元宝解析之前；本版本已改为向自建服务发送带共用凭证的 `GET` 请求，并适配 `code/msg/data` 响应包装。[本地解析入口](../../plugins/wx-video-account-notes/skills/wx-video-account-notes/runtime/resolve_link.py)、[Go 路由](https://github.com/ltaoo/wx_channels_download/blob/124f044235bc706fe796c043a14ff442a150ae5d/internal/adapter/wxchannels/routes.go#L119-L157)

另一条尚未选择的路径是上游 `wx_video_download deploy sph`：它需要 Cloudflare 账号 ID、部署 API Token、元宝 Web Cookie 和独立的 `sphCredential`，并把后两者传为 Worker 环境绑定。它同样需要维护 Cookie，并承担腾讯非公开接口变更的风险。上游明确提示仅供本人使用，公开提供给他人有元宝账号受限风险。[部署配置与提示](https://github.com/ltaoo/wx_channels_download/blob/124f044235bc706fe796c043a14ff442a150ae5d/docs/cli/deploy.md#L128-L169)、[部署绑定](https://github.com/ltaoo/wx_channels_download/blob/124f044235bc706fe796c043a14ff442a150ae5d/internal/workers/sph/deploy.go#L70-L112)、[必填检查](https://github.com/ltaoo/wx_channels_download/blob/124f044235bc706fe796c043a14ff442a150ae5d/internal/workers/sph/deploy.go#L154-L180)

已选的[规格 issue #4](https://github.com/MuZiJin701/wx-video-account-notes/issues/4)使用自有服务器上的上游 Go 解析函数：每次请求从服务器本地文件读取元宝 Cookie，并运行两步解析。公网 Python 入口仅转发解析路由，校验随 Skill 分发的共用凭证并限流。缺 Cookie 会返回 `LOGIN_REQUIRED`，不会退回到需要视频号客户端的路径。2026 年 9 月 29 日已用真实 Cookie 完成公网解析和本机完整验收；后续登录态失效时维护者更新文件即可，无需重启。[Go 两步实现](https://github.com/ltaoo/wx_channels_download/blob/124f044235bc706fe796c043a14ff442a150ae5d/pkg/scraper/wxchannels/yuanbao.go#L104-L247)、[部署说明](../resolver-deployment.md)

安全备注：上游当前 Worker 源码会记录 `generalToken` 和 `exportId` 到日志；自建服务也应检查日志并限制其访问和保留。共用访问凭证按规格放进分发的 Skill，因而不具备保密性；公网 HTTP 也不提供传输保密性。元宝 Cookie 仍须只保存在服务器。现有 `pipeline.py` 会把完整解析响应写入 `raw.json`，其中可能有带令牌的媒体地址；这些产物和原始响应不应进入仓库或公开日志。[上游日志语句](https://github.com/ltaoo/wx_channels_download/blob/124f044235bc706fe796c043a14ff442a150ae5d/internal/workers/sph/worker.js#L318-L335)、[本地写入](../../plugins/wx-video-account-notes/skills/wx-video-account-notes/runtime/pipeline.py)
