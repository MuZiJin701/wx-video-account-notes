# Triage Labels / Triage 标签

The skills use five canonical triage roles. This repo uses the same label strings。
相关 skill 使用五个标准 triage 角色；本仓库直接使用相同的标签字符串。

| Canonical role / 标准角色 | Tracker label / 实际标签 | Meaning / 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate / 维护者需要评估 |
| `needs-info` | `needs-info` | Waiting for reporter information / 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an agent / 已明确，可交给代理执行 |
| `ready-for-human` | `ready-for-human` | Requires human implementation / 需要人工实现 |
| `wontfix` | `wontfix` | Will not be actioned / 不予处理 |

Every triaged issue should carry exactly one category role and one state role。
每个完成 triage 的 issue 应恰好包含一个类别角色和一个状态角色。
