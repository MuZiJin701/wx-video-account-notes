# 模型成稿模板

按 [Skill 成稿规则](../SKILL.md#成稿规则) 读取材料。融合整理与顺序转写分开，保留不确定性；不按样例题材做垂类纠错，也不强改存疑词句。

```md
# 标题

- 原始链接：
- 作者：
- 视频文件或图片素材：

## 内容梗概

建议用 4–8 条交代主题、关键推进和结果。

## 提取到的文案

融合 OCR、ASR、元数据和图片信息，自然分段整理画面文字、口播与上下文。

## 转写文案

以 ASR 为主清理赘词和明显误识别，保留原始表达顺序与细节，不改写为融合概述。

## 提取状态

- 下载：
- OCR：
- ASR：

## 局限说明

标明 OCR / ASR / 元数据 / visual_frames 的来源、失败和理解不确定性。
```
